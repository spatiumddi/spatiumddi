{%- comment -%} Docs page layout — single column, top nav, no sidebar. `root` is a relative prefix ("", "../", "../../") computed from the page's own depth, used for every asset and nav link. Why not site.baseurl: this tree is served from two Pages sites at different mount points (the org site at "/" and the project site at "/spatiumddi/"). GitHub Pages does inject the right baseurl per build, so baseurl would work in production — but it is empty for a local `jekyll build`, which would then emit root-absolute links that only resolve if you happen to serve the output at "/". Relative prefixes are correct at any mount point, production or local, which is what makes the site previewable before it is published. {%- endcomment -%} {%- assign _segs = page.url | split: '/' -%} {%- assign _depth = _segs | size | minus: 2 -%} {%- capture root -%} {%- if _depth > 0 -%}{%- for i in (1.._depth) -%}../{%- endfor -%}{%- endif -%} {%- endcapture -%} {% include head.html root=root %} {% include nav.html root=root %}
